# GUI параллельного CAN-тестирования

Запуск из корня проекта в PowerShell:

```powershell
Set-Location C:\development\BoilerRoomSimulator
C:\Tools\Python311\python.exe parallel_can_gui.py
```

Выберите **один или несколько** разных физических CAN-профилей из `can.ini` и отметьте один или несколько сценариев. Кнопка **Select all** выбирает все сценарии, **Clear all** снимает выбор. Нажмите **Start**. Главное окно показывает сообщения координатора и результаты; для каждого выбранного CAN-профиля открывается отдельное окно с живым журналом контроллера, в том числе при выборе одного профиля. Закрытое окно журнала можно снова открыть кнопкой **Show consoles**.

Сценарии распределяются между свободными контроллерами так же, как при запуске `main.py --no-gui --can-ports ... --scenarios ...`; каждый сценарий выполняется ровно один раз. С одним CAN-профилем сценарии выполняются последовательно, с несколькими — параллельно на разных устройствах. Тесты могут изменять конфигурацию контроллеров и загружать пресеты. Убедитесь, что выбранные устройства и сценарии совместимы, и не используйте эти CAN-адаптеры одновременно в другом приложении.

**Stop** и закрытие главного окна запрашивают штатную остановку. Дождитесь сообщения о завершении очистки, прежде чем закрывать окно или снова запускать тесты. Результаты сохраняются в `log/parallel_can_*/results.json`, журналы устройств — в `worker_<номер>_<профиль>/console.txt` внутри каталога запуска. Путь к конкретному запуску выводится в общем окне. GUI не требует изменения основного интерфейса и не включает UDP-мост.
