# Подключение к контроллеру из GUI

Запустите `main.py` без аргументов. Главное окно откроется без подключения к контроллеру.
Откройте **Config → Подключение…** рядом с меню File: настройки находятся в отдельном
немодальном окне и не занимают место в главном окне приложения.
Генерируемый `gui/wxFormBuilderProject.py` не используется для этого окна и не изменён.

1. Задайте **ID контроллера**: `1–255` для конкретного устройства или `0` для автопоиска.
2. Выберите интерфейс:
   - **CAN** — выберите конфигурацию адаптера из `can.ini`. Параметры адаптера,
     канала и скорости задаются в соответствующей секции этого файла.
   - **UDP** — укажите UDP-порт контроллера (`1–65535`, по умолчанию `31987`).
     Используется существующий CAN-over-UDP мост с локальной виртуальной CAN-шиной;
     физический CAN-адаптер не нужен. Разрешите приложению UDP в брандмауэре.
3. Нажмите **Подключить**. Во время поиска отображается «Подключение…».
   Пресеты и сценарии доступны после появления статуса «Подключено».
4. Для смены ID или интерфейса откройте **Config → Подключение…**, нажмите **Отключить**, дождитесь завершения
   отключения, измените параметры и подключитесь снова.

Кнопка **Закрыть**, Escape и крестик скрывают настройки, но не отключают контроллер.
Главное окно остаётся доступным, даже когда настройки открыты. При повторном открытии
отображаются текущие значения и актуальный статус подключения.

Корректные значения сохраняются при нажатии «Подключить», даже если контроллер
недоступен. Настройки хранятся в `settings.ini` в параметре `connection_settings`
текущего профиля. При следующем запуске без аргументов они появятся в окне настроек,
но подключение по-прежнему нужно подтвердить кнопкой. Переменная `BRS_SETTINGS_PATH`
позволяет переопределить путь к файлу настроек.

Ошибки подключения отображаются в окне настроек и журнале; приложение не закрывается.
Если ресурсы предыдущего соединения не удалось освободить, повторное подключение
блокируется: приложение нужно перезапустить.

При выполнении сценария и загрузке пресета отключение через окно настроек недоступно.
Сначала остановите сценарий через меню Scenario → Stop и дождитесь завершения,
либо дождитесь окончания загрузки пресета. Закрытие приложения доступно всегда.

Запуск с аргументами командной строки сохраняет прежнее поведение: параметры берутся
из аргументов, подключение запускается автоматически, меню Config недоступно.
Сохранённые GUI-настройки не подменяют аргументы CLI.
